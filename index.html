아두이노 연결

진짜 버튼으로 친 점·대시가 여기서 하프·피아노 소리로 나고, 회전 센서 값이 보여요. Chrome 또는 Edge에서만 돼요.

연결 안 됨
  1. 아두이노에 morse_all.ino를 올려요 (Arduino IDE → Upload).
  2. Arduino IDE의 Serial Monitor를 닫아요. 열려 있으면 여기서 연결이 안 돼요.
  3. 위 버튼 → 목록에서 usbmodem…(Arduino Uno) 선택 → 연결.
  4. 부저 소리 없이 웹 소리만 원하면 코드 위쪽 BUZZER_ON을 false로 바꿔 올려요.
