# 모스부호기 웹

아두이노 모스부호기를 웹에서도 쓸 수 있게 만든 페이지예요.

- **치기**: 점 버튼 · 대시 버튼(꾹)으로 모스부호를 치면 하프·피아노·화음·오르골 소리로 울려요.
- **보내기**: 영어·숫자를 모스부호로 바꿔 빛과 소리로 보내요.
- **STILL HERE**: 신호 → 과잉 → 임계점 → 정적 → 숨. 누르고 있으면 멈춰요(여백).
- **아두이노 연결**: Chrome·Edge에서 Web Serial로 아두이노와 연결해, 진짜 버튼 소리와 회전 센서 값을 보여줘요.
- **첫 화면**: 부품 사진과 배선도로 보는 모스부호기 만들기 가이드 (PDF 포함).
- **치기**: `play/` — 보드를 연결해 치면 글자가 써지고 하프·피아노 소리로 울려요.
- **아두이노 코드**: `arduino/morse_all/morse_all.ino`

하프 소리: Freesound 커뮤니티 녹음 (harp D4).
